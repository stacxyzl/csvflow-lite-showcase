# CSVFlow Lite

### Import. Validate. Preview. Export.

**A lightweight React + TypeScript CSV import component by MONO Foundry.**

CSVFlow Lite helps developers integrate CSV upload, parsing, validation, data preview, and JSON export into their applications without building the entire workflow from scratch.

## Features

- **Drag & Drop Upload** — Upload CSV files directly from your browser.
- **CSV Parsing** — Handles quoted fields and common CSV formatting requirements.
- **Data Preview** — Review imported records before exporting.
- **Validation** — Display errors for invalid data.
- **JSON Export** — Convert and download CSV data as JSON.
- **Responsive UI** — Designed for desktop and mobile layouts.
- **Local Processing** — Processes CSV files within the browser.
